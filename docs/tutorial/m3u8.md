# M3U8转MP4教程

```bash
ffmpeg -allowed_extensions ALL -i "test.m3u8" -c copy -bsf:a aac_adtstoasc "test.mp4"
```

## 1. 功能概述

该命令用于将 **M3U8 格式的 HLS 流媒体**（通常由多个 `.ts` 分片文件组成）快速转换为 **MP4 格式文件**，通过直接复制原媒体流（不重新编码）提高转换效率，并确保音频格式兼容 MP4 容器。

## 2. 参数详解

| 参数                      | 含义               | 作用                                                         |
| ------------------------- | ------------------ | ------------------------------------------------------------ |
| `ffmpeg`                  | 命令本身           | 调用 FFmpeg 多媒体处理工具                                   |
| `-allowed_extensions ALL` | 允许所有扩展名     | 允许 M3U8 索引文件中引用的媒体分片（如 `.ts`）使用任意扩展名，避免因扩展名限制导致读取失败 |
| `-i "test.m3u8"`          | 输入文件           | 指定输入源为 `test.m3u8`（HLS 流媒体的索引文件，包含分片视频的路径信息） |
| `-c copy`                 | 编码方式：直接复制 | `-c` 等价于 `-codec`，`copy` 表示直接复制原视频和音频的编码格式（不重新编码），大幅提升转换速度 |
| `-bsf:a aac_adtstoasc`    | 音频比特流过滤器   | 将 AAC 音频的 ADTS 格式（常见于 `.ts` 分片）转换为 ASC 格式（MP4 容器要求的 AAC 格式），确保音频在 MP4 中正常播放 |
| `"test.mp4"`              | 输出文件           | 指定转换后的输出文件为 `test.mp4`                            |
